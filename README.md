# «Ход за ходом» — учебный проект по веб-технологиям

**Тема:** теория игр, задания ЕГЭ по информатике №19–21. **Технологии:** HTML5, CSS3, JavaScript. Никаких Node.js, npm, SQL, Express и серверного API.

## Как запустить

1. Распакуйте архив, откройте папку проекта в VS Code (**File → Open Folder**).
2. Откройте `index.html` в браузере или используйте расширение **Live Server** (правой кнопкой по `index.html` → **Open with Live Server**).
3. Для проверки мобильной версии в Chrome нажмите `F12`, затем `Ctrl+Shift+M` и выберите мобильный экран.

## Соответствие ПР1–ПР6

| Практическая работа | Что реализовано и где показать |
|---|---|
| **ПР1 — семантический HTML** | `index.html`: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; также остальные HTML-страницы |
| **ПР2 — CSS-оформление** | `css/style.css`: цвета, отступы, стили карточек, «чердак» (`.site-header`) и подвал (`.site-footer`) |
| **ПР3 — две колонки, Flexbox, адаптивность** | На главной в блоке «Публикации»: `.articles-layout` задаёт `display:flex`, `.articles-main { flex:7 }` и `.articles-aside { flex:3 }`; при `max-width:768px` колонки встают друг под другом. Также мобильное меню и адаптивные карточки. |
| **ПР4 — темы, лайки, сворачивание** | Переключатель «Тёмная тема» в шапке каждой страницы (`js/main.js` + класс `dark-theme` в CSS); кнопки «♥ Лайк» и «Читать далее» на главной (`js/articles.js`). |
| **ПР5 — динамический рендеринг и живой поиск** | `js/articles.js`: массив объектов `initialArticles`, функция `renderArticles`, обработчик события `input`, фильтрация по заголовку, содержанию и тегам. |
| **ПР6 — Git и GitHub Pages** | Создайте Git-репозиторий, загрузите исходники в GitHub и включите GitHub Pages по инструкции ниже. Настоящую публичную ссылку нужно получить в своём аккаунте — в архиве её нет. |
