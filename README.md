# «Ход за ходом» — учебный проект по веб-технологиям

**Тема:** теория игр, задания ЕГЭ по информатике №19–21. **Технологии:** HTML5, CSS3, JavaScript. Никаких Node.js, npm, SQL, Express и серверного API.

## Как запустить

1. Распакуйте архив, откройте папку проекта в VS Code (**File → Open Folder**).
2. Откройте `index.html` в браузере или используйте расширение **Live Server** (правой кнопкой по `index.html` → **Open with Live Server**).
3. Для проверки мобильной версии в Chrome нажмите `F12`, затем `Ctrl+Shift+M` и выберите мобильный экран.

## ПР6: как выложить проект на GitHub

### Шаг 1. Установить Git и настроить автора

Git должен быть установлен. В VS Code откройте **Terminal → New Terminal** и выполните (подставьте **свои** данные):

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
```

### Шаг 2. Сделать первый коммит

В терминале, открытом в папке проекта:

```bash
git init
git add .
git commit -m "Учебный сайт: HTML, CSS, Flexbox, JavaScript"
git branch -M main
```

### Шаг 3. Создать пустой репозиторий

На https://github.com создайте новый **Public** repository, например `ege-game-theory`. Не добавляйте автоматически README и `.gitignore`: они уже есть локально.

### Шаг 4. Привязать GitHub-репозиторий

Замените `USERNAME` и `ege-game-theory` своими именем профиля и названием репозитория:

```bash
git remote add origin https://github.com/USERNAME/ege-game-theory.git
git push -u origin main
```

При запросе авторизации подтвердите вход. **Не используйте** в `git remote add` просто `https://github.com` — нужен полный URL репозитория.

### Шаг 5. Включить GitHub Pages

Откройте свой репозиторий → **Settings → Pages → Build and deployment**. В Source выберите **Deploy from a branch**, Branch = **main**, папка **/(root)** → **Save**. После публикации ссылка обычно выглядит так:

`https://USERNAME.github.io/ege-game-theory/`

Эту ссылку можно отправить преподавателю. Если репозиторий уже подключён, не нужно повторять `git remote add origin`: обновления загружаются командами `git add .`, `git commit -m "..."`, `git push`.

## Ограничения

- Тест хранит данные через `localStorage` на устройстве посетителя: общей БД результатов учеников нет.
- Вкладка со случайными задачами выбирает из **трёх включённых** в сайт заданий. Сервис КЕГЭ не предоставляет в этом проекте интегрированный API для случайной загрузки.
- Интернет может требоваться для внешней подсветки Python через CDN; базовое отображение кода без неё работает.

В `js/tasks.js` содержатся №31483, №31482, №31157, №25358, №23759 и ранее добавленная №22066. В `js/random.js` случайно выбираются **только пять** новых/указанных номеров (№22066 остаётся в разделе «Разбор задач»). Тексты и Python-код показаны без фотографий, решение можно копировать. Решение №23759 составлено для этого проекта и проверено Python. У №31157 условие задания 19 отличается от обычной игры с гарантированной победой: «после неудачного хода» требует хотя бы один подходящий ход, что отдельно отражено в функции `bad_move_allows_vanya`.

Кнопка КЕГЭ открывает банк задач, а рядом можно скопировать номер для поиска оригинала: прямые ссылки на карточки не удалось подтвердить. Все условия при этом доступны внутри сайта.
